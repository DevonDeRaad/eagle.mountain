# ADMXITURE
This directory contains all of the code and output files from running the program *ADMIXTURE*. Output files with the suffix '.Q' contain the inferred ancestry proportions inferred at each K value (1-10). The subdirectory 'remove.unrelated' contains the details for the secondary run performed without related individuals. The file 'admixture.pdf' shows the results included in the manuscript.

The entire protocol (code plus visualizations) in tutorial style can be viewed here: https://devonderaad.github.io/eagle.mountain/admixture/run.ADMIXTURE.html
