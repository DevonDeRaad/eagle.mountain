### This directory contains the protocols used to extract DNA from degraded museum specimens and prepare DNA libraries for sequencing

- The protocol used for extracting degraded DNA from the toepads of historical museum specimens can be found in the file 'phenol-chloroform-extraction-protocol.pdf' (Taken directly from Tsai et al., 2020; doi: https://doi.org/10.5061/dryad.0nj71g0)
  
- The file 'IDT.xGen.low.input.DNA.WGS.library.prep.protocol.for.Historical.DNA.md' contains the entire protocol used for preparing DNA libraries for sequencing, using the [xGen™ ssDNA & Low-Input DNA Library Preparation Kit](https://www.idtdna.com/pages/products/next-generation-sequencing/workflow/xgen-ngs-library-preparation/dna-library-preparation/ssdna-low-input-dna-library-prep-kit)
