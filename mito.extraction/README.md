This directory contains the files used to create whole mitogenome alignments from the WGS data and construct a haplotype network to identify mitochondrial ancestry. 
- A complete walkthrough of the pipeline with the code used and results shown for mining mitogenomes from WGS data can be found at: https://devonderaad.github.io/eagle.mountain/mito.extraction/perform.mito.extraction.html
- File 'mito.alignment.fa' is a fasta file containing the concatenated (unaligned) mitochondrial genomes called for each sample.
