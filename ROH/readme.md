# Estimating runs of homozygosity (ROH)

Each text file with the suffix '.processed.roh.txt' contains the runs of homozygosity (ROH) called for a single individual sample (one ROH per line). Code for calculating the fROH (proportion of the genome in ROH) in each individual, and then visualizing these values by subspecies, can be found here: https://devonderaad.github.io/eagle.mountain/ROH/calc.fROH.html
