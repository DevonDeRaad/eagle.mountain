# Local Ancestry Inference using ancestryHMM
This repository contains all code necessary to reproduce the ancestryHMM results. Each file with the suffix '.posterior' contains the ancestry state probabilities at all ~27K ancestry informative sites, for each individual. The '.pdf' extension files show the visualization of those ancestry chunks across each chromosome, for each sample. The files 'run.test.ancestryHMM.sh' and 'run.hybs.ancestryHMM.sh' are the custom bash scripts that I wrote to convert a vcf file into the appropriate input for ancestryHMM, restrict the input file to only AIMs, and run ancestryHMM. A full walkthrough of the code used to convert the output files into discrete ancestry chunks and then visualize them across the genome can be found here: https://devonderaad.github.io/eagle.mountain/ancestryHMM/vis.ancestryHMM.html
